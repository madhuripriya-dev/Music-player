# Music Player

A simple nature-themed music player built using HTML, CSS, and JavaScript. It includes playback controls, a playlist, progress tracking, and volume control.

## Features

* Play and pause songs
* Next and previous song controls
* Nature-themed playlist
* Progress bar with seek functionality
* Current time and song duration display
* Volume control
* Automatic next song playback
* Click a playlist item to play a song
* Responsive design

## Technologies Used

* HTML
* CSS
* JavaScript

## Project Structure

music-player/
└── index.html

## How to Run

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Click the play button to start the music.
4. Use the controls and playlist to manage the songs.
